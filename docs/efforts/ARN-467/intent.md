# DSF software factory

Rita wants to operate Deep Sci-fi through agents that understand its code, deployed resources, application flows and participants. Temper is the durable operational model and the existing SDLC record. The agents execute inside shared computers. A privately hosted Foundry workspace supplies direct chat and a view of the same work and outstanding decisions.

This effort delivers the whole operating loop: requested changes through verified deployment, ongoing observation and repair, and isolated experiments whose selected results enter delivery. A dashboard or one successful demonstration is insufficient.

The interview and source/provider/Datadog investigation established these decisions:

- Keep DSF product implementation in its existing repository. Modeling its operation does not migrate Story, World, Dweller or the scientific prediction engine into Temper.
- Keep Intent, Effort, Ask, review and proof as the existing SDLC vocabulary. An Effort requests a deployment; the persistent resource owns the permitted deployment operation.
- Maintain observed resource state, flow dependencies and participant activity automatically. Keep intended configuration distinct. Configuration drift produces an Ask rather than automatic adoption or repair.
- Agents judge ambiguous scope and causes. Mechanical checks enforce resource identity, release revision, isolation, proof and operation state. Do not add a scope classifier.
- Use a private fork of tensorlakeai/foundry. Never modify upstream, publish its private source, or target its infrastructure. All admitted workspace users can act; no additional role hierarchy.
- Agents edit and test natively inside Tensorlake computers and use Temper MCP for recorded actions. Direct Foundry chat and an outside agent both operate the same model.
- Use existing model subscriptions for agent work. Rita authorized at most $200 total additional overnight hosting, computer usage and necessary DSF product API verification. Do not switch agents to API billing automatically.

Rita authorized autonomous implementation, review, deployment and live verification on September 5, 2026 EDT. Concrete provider consent and Cedar decisions still come from the human; the implementer cannot impersonate that authority.
